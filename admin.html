One-time setup required
The Admins tab uses a secure Netlify Function that needs two environment variables set in your Netlify dashboard before it works:

Netlify → Site → Environment Variables → Add:
  SUPABASE_URL — your Supabase project URL
  SUPABASE_SERVICE_ROLE_KEY — from Supabase → Project Settings → API
  SITE_URL — your live site URL (e.g. https://kerproperties.netlify.app)

Then redeploy and this tab will work fully.
